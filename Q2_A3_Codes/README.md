# ResNet-18 CIFAR-10 Pruning Framework

This project trains/loads an ImageNet-pretrained ResNet-18 adapted to CIFAR-10, applies iterative unstructured magnitude pruning and dependency-aware structured channel pruning, fine-tunes both, exports executable PyTorch models, and benchmarks them.

## 1. Setup

Use Python 3.10 or 3.11 for the broadest compatibility with the PyTorch/TorchVision wheels. Create a virtual environment, activate it, then:

```bash
pip install -r requirements.txt
```

The first run downloads CIFAR-10. `train.py` also downloads ImageNet ResNet-18 weights unless `--no-pretrained` is supplied. An internet connection is therefore needed on first run.

## 2. Train the original model

```bash
python train.py --epochs 10 --batch-size 128
```

Output: `artifacts/original_fp32.pt`. This is the baseline FP32 model artifact.

## 3. Generate the unstructured-pruned model

```bash
python prune.py --method unstructured --amount 0.25 --iterations 4 --finetune-epochs 5
```

Magnitude pruning is applied globally to convolutional and fully connected weights. PyTorch masks are applied iteratively and then `prune.remove` makes the zeroed weights permanent in the exported model.

## 4. Generate the structured-pruned model

```bash
python prune.py --method structured --amount 0.25 --iterations 4 --finetune-epochs 5
```

`torch-pruning` builds a dependency graph from a 32x32 example input. Its magnitude-based groups prune channels and propagate corresponding input-channel changes through dependent convolutions and residual connections. The resulting module has physically smaller channel dimensions; it is not merely a model with zero-valued channel masks. The classifier is retained.

## 5. Run inference

```bash
python inference.py --model artifacts/structured_pruned.pt --image sample_cifar_image.png
```

Replace the model path with `original_fp32.pt` or `unstructured_pruned.pt` to use the other versions. Input images are converted to RGB and normalized using CIFAR-10 statistics.

## 6. Benchmark all available models

```bash
python benchmark.py
```

Output: `benchmark_results.csv`, containing test accuracy, test loss, parameter count, theoretical FP32 parameter storage, and measured mean inference time per image on the selected device.

## Outputs

- `artifacts/original_fp32.pt`
- `artifacts/unstructured_pruned.pt`
- `artifacts/structured_pruned.pt`
- `benchmark_results.csv`
- `train.py`, `prune.py`, `inference.py`, `benchmark.py`, `common.py`

## Important experimental notes

- The scripts run real training, pruning, fine-tuning, inference, and benchmarking. The CSV is generated by running the benchmark; no fabricated performance values are included.
- Training defaults are intentionally modest for a coursework run. Increase epochs and tune pruning ratio to study the accuracy/compression trade-off.
- Unstructured pruning creates sparse zero weights but ordinary dense CPU/GPU kernels may not become faster without sparse-kernel support. Its parameter count remains unchanged.
- Structured pruning physically reduces channel dimensions and is more likely to reduce dense inference cost.
- `parameter_size_mb_fp32` is the theoretical size of FP32 parameters only. It excludes serialization overhead, optimizer state, and runtime memory.
- For reproducibility, keep the same hardware, batch size, dataset split, and warmup settings when comparing latency.
- Structured pruning depends on `torch-pruning` compatibility with the installed PyTorch/TorchVision versions. If the library API changes, consult its installed version's documentation.
